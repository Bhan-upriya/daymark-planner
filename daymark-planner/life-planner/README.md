# Daymark — Personal Planner

A responsive personal task planner built with plain HTML, CSS and JavaScript. No framework or installation required.

## Run in VS Code

1. Extract `daymark-planner.zip`.
2. Open the `life-planner` folder in Visual Studio Code.
3. Install the **Live Server** extension (Ritwick Dey), if it is not already installed.
4. Right-click `index.html` and choose **Open with Live Server**.
5. The website opens in your browser.

You can also open `index.html` directly in a browser, but Live Server is recommended while developing.

## Features

- Dashboard with task counts, progress and upcoming deadlines.
- Add, edit, complete and delete tasks.
- Categories, priorities, start dates, deadlines and notes.
- Add subtasks to larger projects.
- Search, filter and sort tasks.
- Schedule grouped by due date.
- Exam countdown (editable from the dashboard).
- Browser `localStorage` persistence.
- Export and import a JSON backup.
- Responsive layout for desktop and mobile.

## Storage note

Tasks are stored in the browser's localStorage on the device/profile where the site is opened. They are not automatically synced between devices or browsers. Use **Export backup** periodically to keep a copy. Clearing browser site data can remove localStorage.

## Customize the sample tasks

The starter list includes five theory subjects, two lab subjects and the goals discussed in the planning conversation. Edit or delete the sample tasks in the website. Rename the seven subject placeholders when you know your subject names.
