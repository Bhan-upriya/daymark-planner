# Daymark – Personal Life Planner

A personal productivity and life-management web application.

🌐 **Live Website:** https://daymark-planner-wine.vercel.app

## Features
- Task management
- Categories and priorities
- Deadlines and scheduling
- Personal productivity dashboard
- Local storage

## Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage
- Vercel (Deployment)

## Deployment
The application is deployed using Vercel.
